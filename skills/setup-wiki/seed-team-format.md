# {TEAM}-profile.md Format

## Structure

```md
# {Context Name}
## 1. Bounded Context

{One or two sentence description of what this team is doing and why it exists.}

## 2. Language

**Term**:
{A one or two sentence description of the term}
_Avoid_: Synonyms that should not be used

## 3. Workflows and Skills

Workflows, skills and tools that are used transforming a context into real world assets.
```
